让调控边的操作机制成为可评分、可审查、可被怀疑者重推的对象。  |  状态快照(诚实分级)

术语约定: 一条调控边写作 R → T(R = 调控因子 / regulator,T = 靶基因 / target); 两个相互竞争的机制假说记作 机制① / 机制②(例:①染色质门控 vs ②TF 浓度动力学)。—— 机制的 ①/② 与调控因子/靶基因是两回事,不要混。

定位: 现有基因调控网络(GRN)基准评估边是否存在(R→T,即"拓扑"); MechanismBench 评估已知边通过何种机制运作(机制分辨),不重做拓扑。

标签如何产生(非循环、可复核): 对每个 (R→T, 诊断性扰动) 单元——

  1. 预注册: 在读取观测之前,冻结机制①、机制② 各自对 T 的方向性预测(仅 上升 UP / 下降 DOWN / 不变 NO_CHANGE,不含幅度),git commit 锁定。
  2. 观测: 从公开扰动数据(nascent RNA / ATAC 等)读出 T 的实际响应方向。
  3. 强制赋标(固定规则): 观测方向 匹配机制①、且与机制②矛盾 → 标签 = 机制①; 匹配机制②、且与机制①矛盾 → 标签 = 机制②; 两者皆不符 / 皆符 / 无法判定 → inconclusive(诚实弃权,保留不丢弃)。

为何只看方向: "幅度多大算显著"可争论,而方向(符号)是二元、可复现、不可抵赖的判据。 标签不取自论文结论,而由 deposited 数据按预注册规则重推——任何人可独立复核。

🕒 3 分钟看懂

已知:「基因 A 调控基因 B」——这叫拓扑(谁管谁),我们知道很多年了。 没解决的:A 到底怎么管 B?光看表达数据(A 高时 B 也高),几种完全不同的物理机制长得几乎一样,分不出来。

🔒 门锁(染色质门控)
A 通过开/关染色质这道"锁"来管 B。
🎚️ 浓度(TF 动力学)
A 靠自身浓度/结合直接调 B 的转录。
⏱️ 频率(转录爆发)
A 改变 B 转录"开火"的频率而非幅度。

为什么必须分清?因为药靶完全不同:门锁→抑制上锁的酶(如 PRC2);浓度→调 A 的量/结合;频率→前两种药可能压根不起作用。搞错机制 = 选错药靶。

核心巧思(诊断性扰动):找一个实验,让两种候选机制给出方向相反的预测——不管结果如何都能一锤定音。 PRC2 门锁比喻:PRC2 是给染色质"上锁"的酶。抑制 PRC2 后——若是门锁机制,锁被打开、B 应有反应;若是纯浓度机制,不涉及锁、B 应毫无变化。 方向相反 → "抑制 PRC2 看 B 变不变"就是天然判官:变→门锁,不变→浓度,都不像→inconclusive(诚实类)。只看方向、不看幅度。

标签哪来?不抄论文结论,而是重看已公开的原始扰动数据、按上面的规则自己判(见 ⑧ 数据来源)——别人能复现你的判断。

「机制①/② 」是通用模板,不止两种:上面用「①染色质门控 vs ②TF 动力学」示范标签逻辑——这只是一个实例。 同一套「机制① vs 机制② + 方向诊断」可套到任何一对竞争机制。本基准已实例化多条「依赖 vs 独立」的机制轴,只是判别读出不同: coactivator 依赖(Mediator / BRD4,读 nascent+ATAC)、looping 依赖(RAD21,读 3D 接触)、remodeler 依赖(SMARCA5,读染色质/间距)、 pause-release 依赖(CDK7)、乙酰化 writer 耦合(读 H3K27ac)、频率 vs 大小(bursting)。完整清单与诚实分级见下方「① 机制轴」表。

诚实说明 · 为什么 PRC2 是比喻而不是数据点:H3K27me3 这把锁稳定、要几天才褪,不匹配本基准的急性窗口(30min–6h)nascent 读出——急性看 PRC2 靶几乎不动,等几天又全是间接效应。 所以门锁"机制"已实现(用更快的染色质因子 BRG1/BCL11A/remodeler 代理),但 PRC2 这个"例子"本身抗拒急性框架:它是完美教学比喻、最差数据点。
